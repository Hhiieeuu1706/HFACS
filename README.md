## Overview

This project explores the application of Artificial Intelligence to aviation accident investigation by automating HFACS analysis.

The system combines Large Language Models (LLMs), a multi-agent reasoning architecture, and rule-based evaluation to support explainable accident classification while maintaining transparency and consistency.

---

## System Architecture

```
Flight Data / Accident Reports
                │
                ▼
      Data Preprocessing
                │
                ▼
      HFACS AI Expert Council
     (Multi-Agent Reasoning)
                │
                ▼
        Rubric-based Evaluation
                │
                ▼
      HFACS Classification
                │
                ▼
        Dashboard & Reports
```

---

## Main Features

- HFACS-based accident analysis
- Multi-agent LLM reasoning
- Explainable AI decision process
- Aviation scenario simulator
- Performance evaluation dashboard
- Automated report generation

---

## Performance

Current evaluation (simulation dataset)

- Precision: 0.58
- Recall: 1.00
- F1-score: 0.73
